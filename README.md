# Dr. Ruhiyyə İbrahimli — Premium Neurology Website

Premium, lightweight, SEO/GEO-oriented personal website for neurologist Ruhiyyə İbrahimli.

## Target stack
- Frontend: Next.js + TypeScript
- Backend/CMS: Django + Django REST Framework
- Database: PostgreSQL
- Styling: modular, responsive UI with Poppins/Montserrat direction
- Content: fully admin-manageable within fixed, safe component contracts

## Core rules
- DEOS ON: PROBE FIRST → MUTATE SECOND → VERIFY ALWAYS
- UNKNOWN ≠ PASS
- Section failure must not become website failure
- Frontend components must not fetch Django endpoints directly
- Frontend must be completed first against typed mock contracts
- Backend must implement the already-frozen contracts
- No unrestricted page builder
- No tiny decorative mobile text
- WhatsApp CTAs must identify source page and CTA position
- SEO/GEO, structured data, internal linking and performance are first-class requirements

## Canonical docs
Architecture and contracts live in /docs and are the source of truth before implementation.
